# NYC Yellow Taxi 2016 — Big Data Analysis

An end-to-end Python analysis pipeline on the NYC Yellow Taxi 2016 dataset: cleaning, EDA, statistics and an interactive dashboard.

## Tech stack
- Python · pandas
- matplotlib / plotly

## Features
- Data cleaning and outlier handling
- Exploratory analysis and pickup/drop-off heatmaps
- Statistical tests (`results/statistics.json`)
- Dashboard script

## Getting started
Download the NYC TLC Yellow Taxi 2016 data (not included because of size), then run the scripts in `scripts/` in order (01 → 04).
